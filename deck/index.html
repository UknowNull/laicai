05

一次自动记账的处理链路

六步管道，全程由确定性代码执行，LLM 不参与。（悬停高亮当前环节）

STEP1
来源预过滤
按包名/标题识别来源，非目标丢弃
→
STEP2
正文提取
extras/MessagingStyle 限长提取
→
STEP3
确定性解析
金额/方向/商户—规则代码抽取
→
STEP4
去重合并
SHA-256 + 时间窗跨渠道合并
→
STEP5
置信度判定
高→入账，低→待确认
→
STEP6
入账/待确认
确认前不影响收支与预算统计
06

LLM 与隐私边界

LLM 在管道外，不触金额账本；隐私随时可关。

D 禁止
金额·借贷方向·余额·去重结果
不由 LLM 决定
C 允许
分类建议·趋势解释·异常提示
自然语言问答·周期报告（可下钩溯）
显式授权 · 最小化上传 · 一键可关

08

隐私与安全

隐私即竞争力，三道防线。

① 正文不落盘
仅内存解析，Android App 无后台联网权限
② 本地加密
PBKDF2-SHA256 310k 次 + AES-256-GCM，导入前校验
③ 分析可控
LLM 显式授权、最小化上传、一键关闭
