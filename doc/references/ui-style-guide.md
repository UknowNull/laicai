# 三版视觉系统归纳（references）

> 来源：`prototypes/{minimal,fashion,luxury}.html` 视觉实现归纳；当前事实以代码为准。

## 简约（墨与账本）

- 纸 #F7F4EE · 墨 #1E1C19 · 朱砂 #B4552D（强调）
- 宋体（衬线）展示字、tabular-nums 数字
- 基调：账本数字栏（结余/支出/收入），UI 克制

## 时尚（流动的金币）

- 石墨 #0E0F0D · 荧绿 #C8F135（UX 900）· SF Mono 金额
- pill 胶囊 Tab、整屏大卡 + Live 呼吸点
- 基调：实时感、大数字、收支双卡

## 奢华（鎏金钱庄）

- 深绿 #101A17 · 金 #C7A25B · 细金线
- 衬线宽字距展示字、钻石 Tab 指示器
- 基调：SVG 金色资产环（环形占比）+ 结余居中

## 三版共同点

同一份演示数据、同一功能点集（同芯异壳）；差异仅在 Token（色/字体/圆角/动效）与骨架（首页/Tab/流水行）。
