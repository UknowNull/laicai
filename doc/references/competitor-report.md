## 核心结论

1. **Android 通知捕获是市场断层优势**：主流记账 App 未把 Android 通知实时自动记账做透（多为手动 + 弱解析），机会在「新一轮通知自动记账 + LLM 兜底与解释」。
2. **iOS 实时通知读取不可行**：系统限制（不可读其他 App 通知正文）→ iOS 走分享扩展 + 文件导入维持一致体验。
3. **隐私优先是差异化**：通知正文敏感；「仅内存解析、不落盘、显式授权」可成为卖点。
4. **错账是最大流失点**：确定性解析 + 待确认兜底降低误记率。
5. **开源策略**：MIT/双许可，规避 GPL 依赖；竞品（如 Mymo）可启发设计但不得引入其代码。
