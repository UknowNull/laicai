# ADR-003-deterministic-first

status: accepted
date: 2026-08-17
related_domains:
  - ledger-engine
  - analysis-llm
  - auto-capture

## 背景

记账产品的信任核心是「记录正确」。若用 LLM 解析金额/方向会产生不确定性；若把它当营销噱头则伤害数据质量。

## 决策

采用「确定优先」原则：
- 金额、借贷方向、去重、余额由确定性代码（规则解析器 + 数值校验）控制，LLM 不得决定交易数值（`INV-MONEY-02`）。
- LLM 只用于：分类建议、趋势解释、异常提示、自然语言分析，且输出必须可下钻到原始交易。
- 低置信/分类不明确记录进入待确认（`INV-CONF-01`），确认前不影响统计。

## 后果

- 解析器为规则代码，与支付文案对抗依赖样本库回归（而非模型微调）。
- 报告/问答需要「指标 + 覆盖度 + 未确认数」的最小上下文，避免误导。
- 对外表述诚实：自动归集可获取的交易 + 便捷导入确认。
