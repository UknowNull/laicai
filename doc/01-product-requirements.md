# 来财记账 产品需求基线

> 本文件是产品验收基线（权威入口）。需求与设计阶段的完整全文见根目录 `PRD.md`（保留追溯）。

## 1. 产品目标

1. 将「记账」从手动劳动收敛为自动：Android 实时捕获支付通知并自动入账。
2. 覆盖跨端：iOS 用户通过账单导入与便捷确认获得一致体验。
3. 用确定性代码保证金额、方向、去重、余额正确；LLM 只做解释与建议。
4. 隐私内建：通知正文不落盘、云端分析显式授权可关闭。
5. 开源（MIT/双许可），不引入 GPL 依赖。

## 2. 核心用户场景

| 场景 | 输入 | 输出 | 状态 |
| --- | --- | --- | --- |
| 买完即记 | 支付通知（微信/支付宝/银行） | 自动入账，0 操作 | 规划（Android） |
| 待确认兜底 | 低置信记录 | 1 秒确认/修改/忽略 | 规划 |
| 历史账单导入 | 微信/支付宝 CSV/OFX/PDF | 映射、去重、入账 | 规划 |
| 月底复盘 | 账本 | 确定性指标 + LLM 周期报告（可下钻） | 前端模拟已实现 |
| 自然语言问答 | 问句 | 基于已验证账本的回答 | 前端模拟已实现 |

## 3. 功能基线（带编号）

### 3.1 自动记账（Android · P0）

- `AUTO-01`：来源预过滤（包名/应用名/标题），非目标通知读取完整字段前直接丢弃。P0，规划。
- `AUTO-02`：通知正文提取（extras、MessagingStyle、tickerText），限长。P0，规划。
- `AUTO-03`：确定性解析（金额、收支方向、商户、时间）。P0，规划。
- `AUTO-04`：置信度判定；不足则进入待确认。P0，规划。
- `AUTO-05`：SHA-256 去重与跨渠道时间窗合并。P0，规划。
- `AUTO-06`：自动入账/待确认分流；确认前不影响收支与预算。P0，规划。
- `AUTO-07`：后台可靠性（重绑定、退避重试、进程恢复、Android 15 敏感正文处理）。P1，规划。
- `AUTO-08`：账户自动匹配（银行/卡号尾号，默认通用账户兜底）。P1，规划。

### 3.2 手动记账（双端 · P0）

- `MAN-01`：快速记一笔（金额键盘、收支切换、分类、账户、备注，连续记多笔）。P0，React 骨架已实现。
- `MAN-02`：账户管理（多账户、余额初始化与调整）。P0，原型占位。
- `MAN-03`：分类管理（预置 + 自定义 + 图标颜色）。P0，原型占位。

### 3.3 账本与查询（双端 · P0）

- `LED-01`：流水列表（时间倒序、按日分组、滚动）。P0，React 骨架已实现。
- `LED-02`：筛选与搜索（分类/账户/收支/时间范围/关键词）。P0，React 骨架已实现。
- `LED-03`：交易详情/编辑/删除/撤销。P0，React 骨架已实现（撤销演示）。
- `LED-04`：首页总览（结余/支出/收入、最近流水、待确认角标、资产概览）。P0，React 骨架已实现。
- `LED-05`：本地数据库（原生 SQLite，金额整数存储）。P0，**设计完成（SQLite schema 定稿）**，实施待开始（M1）。

### 3.4 账单导入（双端 · P0–P1）

- `IMP-01`：微信/支付宝 CSV 官方模板解析 + 去重导入。P0，规划。
- `IMP-02`：通用 CSV/OFX/QIF 导入映射器（列→标准字段），预览 + 确认。P1，规划。
- `IMP-03`：PDF/OCR 票据识别。P1，规划。
- `IMP-04`：共享扩展/文件导入（iOS 关键入口）。P1，规划。
- `IMP-05`：导入去重（金额+时间+来源窗口比对）。P0，规划。

### 3.5 周期分析与 LLM（P1 · 显式授权）

- `ANA-01`：确定性月度指标（支出/收入/结余、分类占比、环比、Top 商户、预算偏差），纯规则计算。P1，前端模拟已实现。
- `ANA-02`：周期报告（LLM）：自然语言总结、异常提示、节省建议；含覆盖度与未确认数声明；可下钻。P1，前端模拟已实现。
- `ANA-03`：自然语言问答。P1，前端模拟已实现。
- `ANA-04`：授权与开关（首次显式授权、设置一键关闭）。P1，React 骨架已实现占位。
- `ANA-05`：数据最小化（仅上传问题所需指标/交易子集）。P1，规划。

### 3.6 设置与安全（双端 · P0）

- `SEC-01`：加密备份/恢复（PBKDF2-SHA256 高迭代 + AES-256-GCM）。P0，规划。
- `SEC-02`：隐私开关（云端授权、正文不落盘声明、数据导出）。P0，原型占位。
- `SEC-03`：通知权限引导与监听状态页。P0，规划。

### 3.7 主题体系（当前已实现 · 支撑 UI 工程）

- `THEME-01`：三套 Design Token（简约/时尚/奢华），运行时切换 + localStorage 记忆。P0，已实现。
- `THEME-02`：布局骨架三变体（Home ledger/hero/ring、Tab text/pill/diamond、Row line/capsule）。P0，已实现。
- `THEME-03`：新增主题规范化（复用 Token 表，不复制引擎）。P0，已实现（见 `domains/theme-system.md`）。

### 3.8 非目标（明确不做）

- ❌ iOS 实时通知读取（系统限制，不可行）
- ❌ 证券/股票类资产管理、社交社区
- ❌ 银行 Open Banking 直连（阶段四视市场再评估）
- ❌ 多币种换汇（首版人民币本位）

## 5. 验收指引

- 自动记账：微信/支付宝/≥3 家银行通知可自动入账；误记率可观测；待确认流闭环。
- 导入：主流账单格式一次导入去重正确；iOS 可独立使用。
- 分析：报告结论全部可下钻；关闭云端后功能不降级。
- 主题：三版可运行时切换；数据与交互一致；构建产物无 pageerror。
